# Step 2 — Architecture

Prerequisite: the user has approved `requirements.md`.

1. Recommend an architecture that satisfies `requirements.md` only. Include:
   - A mermaid component diagram
   - Each component and its responsibility
   - The technology choice and why it fits the requirements
   - Data flow from the user input to the documentation file
   - Where secrets are kept out of logs and the snapshot
2. Write that recommendation to `architecture.md`.
3. List assumptions in their own section. Wait for the user to accept or change them.
